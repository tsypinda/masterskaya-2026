# Схемы работы чат-бота

## 1. Use Case — Чат-бот

* **Актор:** Клиент банка
* **Система:** Чат-бот
* **Сценарии использования (Use Cases):**
  * Ознакомиться с возможностями чат-бота
  * Задать вопрос в свободной форме и найти подходящую тему по смыслу и синонимам
  * Получить ответ на вопрос
  * Перейти к оператору
  * Завершить диалог
  * Посмотреть историю диалога
  * Выбрать категорию обращения

---

## 2. Гипотеза 1

1. **Старт.**
2. Клиент начинает диалог с ботом.
3. Бот отвечает; кнопка «Связаться с оператором» постоянно доступна.
4. **Развилка:** *Клиент получил ответ?*
   * **Да** → Завершает диалог.
   * **Нет** → Выбирает переход на оператора → Видит предупреждение и примерное время ожидания → Подтверждает переход или остается с ботом.

---

## 3. Гипотеза 2

1. **Старт.**
2. Клиент открывает чат.
3. Бот предлагает категории обращений.
4. **Развилка:** *Клиент выбирает подходящую категорию?*
   * **Да:**
     1. Бот показывает варианты вопросов.
     2. **Развилка:** *Клиент находит подходящий вопрос?*
        * **Да** → Бот предоставляет ответ → Завершение диалога.
        * **Нет** → Бот предлагает альтернативный способ → переход к **объединению альтернативных вариантов** (шаг 5).
   * **Нет:**
     1. Бот предлагает альтернативный способ → переход к **объединению альтернативных вариантов** (шаг 5).
5. **Объединение альтернативных вариантов (ветвление):**
   * **Связаться с оператором** → Завершение диалога.
   * **Посмотреть другие категории** → возврат к выбору подходящей категории (шаг 4).

---

## 4. Гипотеза 3

1. **Старт.**
2. Клиент открывает чат.
3. Бот предлагает категории обращений и поле для вопроса в свободной форме.
4. Клиент вводит вопрос, например: `"У меня не вернулись деньги за отменённую покупку"`.
5. Бот сопоставляет вопрос с темами базы по смысловым совпадениям и синонимам, а затем ранжирует подходящие варианты.
6. **Развилка:** *Бот нашёл подходящие варианты?*
   * **Да:**
     1. Бот показывает несколько наиболее релевантных вариантов.
     2. **Развилка:** *Вариант подходит?*
        * **Да** → Клиент выбирает нужный вариант → Бот предоставляет ответ → Конец диалога.
        * **Нет** → переход к **объединению при отсутствии подходящего варианта** (шаг 7).
   * **Нет:**
     1. Бот предлагает альтернативные варианты продолжения → переход к **объединению при отсутствии подходящего варианта** (шаг 7).
7. **Объединение при отсутствии подходящего варианта (ветвление):**
   * **Переформулировать вопрос** → возврат к вводу вопроса клиентом (шаг 4).
   * **Посмотреть категории** → возврат к выбору категории (шаг 3).
   * **Связаться с оператором** → клиент нажимает постоянно доступную кнопку внизу чата и подтверждает переход.
