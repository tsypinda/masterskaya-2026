# Прототип чат-помощника банка

Интерактивный MVP-прототип реализован на чистых HTML, CSS и JavaScript без установки зависимостей.

## Запуск

Откройте файл `index.html` в браузере.

## Реализованные сценарии

- постоянная кнопка «Связаться с оператором» с предупреждением о времени ожидания;
- краткое описание возможностей и выбор категории обращения;
- выбор конкретного вопроса и получение ответа;
- поиск по ключевым словам;
- сценарий отсутствия совпадений;
- переформулировка запроса и возврат к категориям;
- подтверждение перехода к оператору;
- завершение диалога;
- адаптация интерфейса для мобильных экранов.
- поиск по синонимам и ранжирование релевантности;
- сохранение истории завершённых диалогов в localStorage;
- локальная аналитика событий и экспорт CSV;
- клавиатурная навигация, skip-link и индикаторы фокуса;
- страница тестов `test.html` для проверок поисковой логики.

## Демо-режим администратора

Введите `admin` в поле поиска, чтобы включить разработческие элементы: оценку релевантности, тесты, аналитику и перезапуск прототипа. Нажмите «Выйти», чтобы скрыть их. Режим действует в текущей вкладке.

Это демонстрационный переключатель интерфейса, а не настоящая авторизация: пароль или серверная проверка не используются, и он не защищает данные или исходный код.
